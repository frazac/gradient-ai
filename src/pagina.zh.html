    AI 梯度

    人工智能融入层级

    简介

    五个梯度，用来说明人工智能模型在一项工作、一个项目、一项任务或一段简单文字中的参与程度。在本网站上，你还可以定制这些印章：既可以按使用场景调整，例如用于教学，并按学科类型区分；也可以调整外观，改变颜色、粗细和尺寸。

    本页为简体中文译本。AI 梯度最初以意大利语写成，中文版由意大利语原文翻译而来，尚待以中文为母语的人士审校。如发现不准确或不自然的表述，欢迎在 GitHub 上提出建议。

    如果你能阅读英文，建议先阅读原版 AI Assessment Scale（AIAS，AI 评估量表），作者为 Mike Perkins、Leon Furze、Jasper Roe 和 Jason MacVaugh。

    如何使用印章

    有四种方式，从最简单到最灵活。示例使用第 3 级，并链接到本网站上该层级的说明；形状、颜色和粗细跟随上方面板中的选择。

    固定副本还是始终最新？

    • 下载的文件（SVG、PNG）：是你自己的副本，之后不会再变。
    • 本页提供的代码（PNG 图片、SVG 文件、JavaScript）：与地址中写明的版本绑定，目前是 0.6.1。即使项目更新，你看到的仍是这个版本，直到你修改版本号。
    • 本网站始终显示最新版本：带链接的文本会指向这里最新的层级说明。

    如果层级需要以长期不变的方式声明，例如写进合同、任务说明或项目征集公告，请使用下载的文件或下面的代码。

    1. 纯文本，带链接

    适用于文档、邮件、教学平台和网站：一行文字说明层级，并链接到该层级的说明。每个层级下的“复制带链接的文本”按钮会直接复制这行文字；粘贴到 Word、Google 文档或邮件中，链接依然可以点击。

    2. PNG 图片

    适用于幻灯片、文档以及只接受图片的平台。每个印章都有 128 和 512 像素两种尺寸（图标：64 和 256；标签：高 48 和 192），分描边和填充两种样式。

    4. JavaScript

    用一个属性标出位置，脚本库就会绘制印章，颜色和粗细可以自选。

    选项：variant（stamp、icon、label）· lang（zh、it、fr、en）· color · from/to（五级渐变）· palette（五种颜色）· weight（1–3）· filled · size（像素）· link（默认情况下，印章链接到本网站上对应层级的说明；设为 false 可去掉链接，也可以填写某个场景页面的地址）。只需要 SVG 字符串时：GradientAI.toSvg(3, {variant: 'stamp', lang: 'zh'})。

    本项目如何使用 AI

    内容

    作者负责改编和基本选择：层级名称、使用场景、职场与教学的侧重。文本由作者给出方向，与 AI（Claude）共同撰写；作者审阅、修改，并对照 AIAS v2 核实。

    中文翻译

    中文版由 AI（Claude）按照作者的要求从意大利语翻译而来，并参考了英语和法语版本。层级名称和术语由作者确定方向；译文尚待以中文为母语的人士审校。

    颜色

    AI 提出了最初的十种色调和用来调整它们的工具，并测量了对比度和色相差异。作者确定方向，凭肉眼调整颜色；部分最终色调由 AI 按照作者的要求选定。

    网站、代码和设计

    网站、JavaScript 脚本库、构建工具、印章和 GitHub 仓库均使用 Claude Code 完成。作者确定目标和设计选择，并检查和测试了结果。

    开展合作研究

    AI 梯度适合在实际使用中加以研究：教师、学生和委托方如何理解这些层级，它们是否有助于申报 AI 的使用，以及层级之间的界限在哪些地方不够清晰。如果有大学、院系或研究中心希望就此开展研究，作者愿意合作：研究资助或奖学金、访问学者（visiting fellowship）、联合研究项目。
